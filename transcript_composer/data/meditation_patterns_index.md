# Meditation Script Pattern Index

> **Purpose:** This file is a structural blueprint for creating new wellness content — guided meditations, scripts, audio sessions — that serve the same healing function as the existing video library. Each pattern was extracted by analysing real transcripts. Every pattern is tagged with the Generation, Wound, Stage, Pillar, Principles, and Mood from the content library so new content can be created that fits precisely into the same taxonomy.

> **How to use:** Pick a Generation → pick a Wound → pick a Stage → find a matching pattern below → follow the canonical pattern and instruction rule to write new content. Load `meditation_patterns_examples.md` alongside this for real phrasing and tone reference.

#### `opening_intro_spaciousness`
- **Placement:** opening
- **Canonical pattern:** open to spaciousness → invite receptivity → welcome messages
- **Instruction rule:** Guide the listener to expand their awareness and be open to what arises — no fixing, just receiving
- **Use case:** Best for content where the user arrives overwhelmed or scattered and needs space before any body work

#### `guided_meditation_intro`
- **Placement:** opening
- **Canonical pattern:** introduce journey → frame purpose → emphasize relaxation → invite presence
- **Instruction rule:** Tell the listener what this session is for. Frame it around their specific wound — name the feeling without diagnosing it. Make it feel like permission.
- **Use case:** Use when the content has a clear therapeutic purpose tied to a wound. This sets the container before the body work begins.

#### `grounding_settling_posture`
- **Placement:** pre_scan_settling
- **Canonical pattern:** establish comfort → secure support → quiet attention → settle into practice
- **Instruction rule:** Guide the listener to find a position they do not have to hold. Emphasise safety and ease. Signal the body that it is allowed to stop performing.
- **Use case:** Always use before any body scan or somatic work. Essential for users in chronic tension or hypervigilance.

#### `somatic_scan`
- **Placement:** middle
- **Canonical pattern:** initiate awareness → scan body → notice tension → release tension
- **Instruction rule:** Move awareness slowly through the body top to bottom. Name specific body parts. Do not rush. Invite release without demanding it.
- **Use case:** Core pattern for body awareness pillars (P01, P03). Use for any wound where the body is the primary site of holding.

#### `breath_attention`
- **Placement:** middle
- **Canonical pattern:** notice sensations → widen attention → embrace sounds → relax in awareness
- **Instruction rule:** Start with breath sensation. Gradually widen to include sounds, air on skin. Let the listener expand outward without losing the breath anchor. Acknowledge that the mind will drift — normalise it.
- **Use case:** Universal. Works at all stages. Especially valuable for anxious users who need a concrete anchor.

#### `mind_reframing_kindness`

- **Canonical pattern:** release tension → heal from within → observe sensations → accept experiences → notice opposites
- **Instruction rule:** Guide the listener to notice the opposites present in their experience (tension/ease, pain/comfort). Do not resolve — just observe. Then invite a gentle inner healing quality without naming it as love or spirituality unless appropriate.

#### `mind_reframing_oneness`
- **Placement:** middle
- **Canonical pattern:** let go into gravity → feel freedom and expansion → release boundaries → embrace spaciousness → experience oneness
- **Instruction rule:** Guide from physical letting go (gravity, weight) into a widening sense of connection. The progression is: body → space around body → connection to all. Do not force the spiritual register — let it emerge from the physical.
- **Use case:** Most effective for Belonging wounds and for users at Stage 3+ who are ready for an interconnection experience.
